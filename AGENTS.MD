# Portfolio — Development Guidelines

## Stack
- React + Vite + TypeScript
- Motion for React
- CSS responsivo
- Componentes reutilizáveis

## Skills por tarefa
- Direção visual: frontend-design
- Design system: ui-ux-pro-max
- Animações: animate
- Performance de animações: animation-performance
- Performance React: vercel-react-best-practices
- Acessibilidade: web-design-guidelines
- Arquitetura: vercel-composition-patterns
- Simplicidade: ponytail

## Processo obrigatório
1. Ler este AGENTS.md antes de implementar.
2. Identificar as skills relevantes para a tarefa.
3. Consultar suas instruções antes de escrever código.
4. Preservar a identidade visual do projeto.
5. Evitar dependências e abstrações desnecessárias.
6. Garantir responsividade e acessibilidade.
7. Respeitar prefers-reduced-motion.
8. Verificar o build e revisar o resultado.

## Direção de design
- Interface premium, autoral e minimalista.
- Tipografia e composição como elementos centrais.
- Animações elegantes, fluidas e intencionais.
- Evitar layouts genéricos de portfólio.
- Priorizar desempenho e experiência mobile.
